# Account Digilocker

A secure personal information manager written in C. Users create an account with a unique ID and password, and their personal details are stored in an encrypted form. Built following secure C coding standards.

## Features

- Account creation with a unique ID and password login
- Encryption of stored personal information
- Add, view, and manage saved records

## Files

```
New.c, Existing.c    account creation and login
Encrypt.c, Decrypt.c encryption and decryption
PersonalInfo.c       record management
functions.h          shared helpers
```
